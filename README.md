# منصة تسامي لحلول الأمن والسلامة | TASAMI SAFETY SOLUTION
> **شعارنا: — سلامتك أمانة —**  
> منصة ويب متطورة وعصرية لشركة أمن وسلامة معتمدة، متوافقة مع متطلبات كود البناء السعودي (SBC) والدفاع المدني ومستهدفات رؤية المملكة 2030.

---

## 🌟 مميزات المنصة الرئيسية

1. **تصميم مطابق وفاخر (Luxury & High-Trust UI):**
   - ألوان الهوية: الأسود الفحمي، الرمادي المعدني، وتدرجات الذهب الفاخر (`#c59a45`).
   - دعم كامل للغتين: العربية (افتراضياً RTL) والإنجليزية (LTR) بضغطة زر واحدة.
   - شعار ثلاثي الأبعاد هندسي متطابق مع هوية "تسامي".

2. **أقسام متكاملة:**
   - **الترويسة (Navbar):** تنقل ذكي، زر بحث، تبديل اللغة، وزر "طلب استشارة" دائم.
   - **البنر الرئيسي (Hero):** عنوان رئيسي جذاب، أزرار دعوة للإجراء، والركائز الأربع المعتمدة.
   - **من نحن (About Us):** قصة الشركة، إحصائيات معتمدة (+500 عميل، +1,200 مشروع، +10 سنوات)، وتوافق مع رؤية 2030.
   - **خدماتنا (Services):** بطاقات تفاعلية تشمل: السلامة من الحريق، إدارة المخاطر، التدريب والتأهيل، الاستشارات الهندسية، والتدقيق والامتثال مع نوافذ تفصيلية للاشتراطات الفنية.
   - **أبرز مشاريعنا (Projects):** معرض مشاريع قابل للفلترة (مجمعات تجارية، أبراج مكتبية، منشآت صناعية).
   - **حاسبة السلامة الذكية (Interactive Safety Estimator):** أداة حصرية لحساب المتطلبات والأنظمة الإلزامية والتكلفة التقديرية بالريال السعودي حسب مساحة ونوع المنشأة ودرجة الخطورة.
   - **طلب استشارة منبثق (Consultation Modal):** نموذج طلب مدمج ومباشر.
   - **لوحة إدارة الطلبات (Admin View):** نافذة مباشرة لعرض الطلبات والرسائل الواردة من العملاء.

## 🚀 كيفية تشغيل المشروع محلياً (Local Development)

### 1. المتطلبات:
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).

### 2. تثبيت الحزم:
```bash
npm install
```

### 3. تشغيل خادم الواجهة الخلفية (Backend API):
```bash
node server/server.js
```
*(يعمل الخادم على المنفذ `http://localhost:5000` وينشئ قاعدة بيانات SQLite تلقائياً في `server/data/tasami.sqlite`)*

### 4. تشغيل واجهة الموقع (Frontend):
في نافذة موجه أوامر جديدة:
```bash
npm run dev
```
افتح المتصفح على الرابط: `http://localhost:3000`

## 🐙 خطوات رفع المشروع على GitHub (خطوة بخطوة)

إذا لم تكن قد قمت برفع المشروع على GitHub من قبل:

1. افتح حسابك على [GitHub.com](https://github.com) وأنشئ مستودعاً جديداً (New Repository) باسم مثلاً: `tasami-safety-platform`.
2. في مجلد المشروع في جهازك، افتح الطرفية (Terminal / PowerShell) ونفذ الأوامر التالية:

```bash

git init

# 2. إضافة كافة الملفات (ملفات node_modules مستثناة تلقائياً عبر .gitignore)
git add .

# 3. حفظ التغييرات الأولى
git commit -m "Initial commit: Tasami Safety Platform v1.0"

# 4. تحديد الفرع الرئيسي
git branch -M main

# 5. ربط المستودع المحلي بمستودعك على GitHub (استبدل الرابط برابط مستودعك)
git remote add origin https://github.com/USERNAME/tasami-safety-platform.git

# 6. رفع الكود
git push -u origin main
```

## 🗄️ ماذا تفعل بخصوص قاعدة البيانات (Database)؟

حالياً، المشروع مزود بمحرك قاعدة بيانات **SQLite مدمج ومباشر** يعمل بدون أي إعدادات إضافية (`server/server.js`).

### للتشغيل الفعلي على الإنترنت (Production):
لديك عدة خيارات ممتازة ومجانية/منخفضة التكلفة:

1. **الخيار الأول (الأسهل والأقوى - Supabase أو PostgreSQL):**
   - سجل في [Supabase](https://supabase.com).
   - يعطيك قاعدة بيانات PostgreSQL سحابية جاهزة مع واجهة تحكم كاملة وجدول للطلبات والرسائل.
   - ستحصل على رابط اتصال (`DATABASE_URL`) تضعه في متغيرات البيئة.

2. **الخيار الثاني (Firebase Firestore):**
   - إذا كنت تفضل حلول Google Cloud / Firebase، يمكنك ربطه بـ Firestore لتخزين طلبات الاستشارة وتلقي إشعارات فورية عبر البريد عند كل طلب جديد.

3. **الخيار الثالث (استمرار استخدام SQLite على VPS):**
   - إذا استضفت المشروع على خادم افتراضي خاص (VPS مثل DigitalOcean أو Hetzner أو AWS Lightsail)، فإن ملف الـ SQLite الحالي سيعمل بكفاءة فائقة وسرعة هائلة دون الحاجة لأي سيرفر قاعدة بيانات منفصل!
